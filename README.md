# 🚀 TaskFlow AI — Productivity & Task Management Dashboard

> لوحة تحكم تفاعلية متقدمة لإدارة المهام وتتبع الإنتاجية، مصممة بأحدث تقنيات الـ Frontend وتوفر تجربة مستخدم سلسة واحترافية تشبه منصات الـ SaaS الحقيقية.

---

## 🌟 Features (المميزات الرئيسية)

* **Kanban Board مع السحب والإفلات (True Drag & Drop):** مدعومة بمكتبة `@dnd-kit` لتنقل سلس بين حالات المهام (*قيد الانتظار، قيد التنفيذ، مكتملة*).
* **إدارة الحالة العالمية (Zustand with Persistence):** تخزين دائم لحالة المهام واختيار الثيم في الـ `LocalStorage` لضمان عدم فقدان البيانات عند إعادة التحميل.
* **تبديل الأوضاع (Light / Dark Mode):** واجهة عصرية تدعم الوضعين الداكن والفاتح مع انتقالات مرنة.
* **البحث والتصفية الفورية (Real-time Search & Priority Filters):** إمكانية البحث السريع عن المهام وفلترتها حسب الأولوية (*عالية، متوسطة، منخفضة*).
* **إحصائيات فورية (Analytics & Metrics):** حساب تلقائي لنسب الإنجاز، إجمالي المهام، والمهام المكتملة بلحظتها.
* **تصميم متجاوب (Fully Responsive):** متوافق تماماً مع جميع الشاشات (الهواتف، الأجهزة اللوحية، وأجهزة الكمبيوتر).

---

## 🛠️ Tech Stack (التقنيات المستخدمة)

* **Framework:** Next.js 15 (App Router)
* **Language:** TypeScript
* **State Management:** Zustand (with persist middleware)
* **Styling & UI:** Tailwind CSS & Lucide Icons
* **Drag & Drop:** `@dnd-kit/core`
* **Typography:** Cairo Font (Google Fonts)
